# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind.

Enforcement is a human matter and is handled exclusively by the project
operator, [@bugabinga](https://github.com/bugabinga) — agents never moderate
people. Report violations privately via
[GitHub's report abuse form](https://github.com/contact/report-abuse) or by
contacting the operator through their GitHub profile.
