# The library half of the FIT matrix (ADR-0064): one idiom the genre shares per
# row, the genre being flate2, zstd, xz2, brotli and lz4_flex (snap and ruzstd
# as pure-Rust references). tests/fit_lib.rs probes each row against the built
# crate and fails when a recorded state disagrees with the observation, so a
# flip is a diff to this file. .github/scripts/status-data.py reads the same
# file: FIT's library half is the `holds` rows over all rows.
#
# Format: id | state | behavior | citation | note
#   state     holds, gap, or declined. A declined row stays in the denominator
#             and has no probe; its note is the reason.
#   citation  crate version and item as read from the registry source of that
#             version (`cargo add`, in a scratch crate outside this checkout),
#             or the run that observed it. The page is
#             https://docs.rs/<crate>/<version>/<crate>/<path>; it is where a
#             reader goes, not where the evidence came from. Versions read on
#             2026-10-11: flate2 1.1.10, zstd 0.14.2, xz2 0.1.7, brotli 9.0.0,
#             lz4_flex 0.14.0, snap 1.1.2. A crate that lacks the idiom is not
#             cited.
#   note      optional; where the genre splits, the split and the choice.
#
# A row with a file tests/fit/lib/<id>.rs is probed by compiling that file
# against the built crate: it is the idiom as a user writes it, and the row
# holds when it compiles. The names in a gap row's file follow the genre's
# (zstd's `write::Encoder`); the issue that closes the gap updates the file to
# the names it picks in the same diff. A row without one is probed in
# tests/fit_lib.rs by running the behavior.
